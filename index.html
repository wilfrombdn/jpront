Features

  • Adapters: NEXIQ USB-Link 3, Noregon DLA+ 2.0 / 3.0 (any RP1210 driver)
  • Live data: about 60 J1939 readings on Windows (about 90 on Linux), graphs of up to 8 readings at once, min / max, recording, CSV export
  • Faults: active and past codes, lamps, plain-English meanings, freeze frames; standard clearing on Windows
  • Scanner: ECU requests, identity, full-vehicle health report (PDF)
  • Module makes and models (Linux): engine, transmission, ABS and dash brands shown from what each module broadcasts, e.g. Cummins, Allison, Meritor WABCO
  • Linux direct adapter: Noregon DLA+ 3.0 straight over USB, no Noregon driver needed (listen-only)
  • Bus tools: CAN logging, playback, filters, bus load, ECU discovery
  • Records: vehicle info, inspection checklists, visit history, CSV / PDF export
  • Windows app: light and dark mode, connection status that turns amber if the vehicle goes quiet

Listens by default. On Windows an optional scanner asks modules for data and can clear standard fault codes (DM3 / DM11) after safety checks and a second confirmation; clearing has not been tried on a truck yet. It never commands a component. Linux only listens. Windows: tested on two school buses with a Noregon DLA+ 3.0. Linux: not yet tested on a real vehicle.

All versions stay below 1.0 until the app is finished and shop-ready. Releases were renumbered on Oct 20, 2026 (1.8.0 is now 0.8.0, 1.11.0 is now 0.11.0).
